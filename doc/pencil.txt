*pencil* *pencil.nvim*
                        pencil.nvim user manual

Pencil presents a centered writing column with visual wrapping. It is a
binary, buffer-local state: enabled or disabled. The bare |:Pencil| command
works without calling setup().

Supported version: Neovim 0.10 or newer. Vim is unsupported. Pencil has no
runtime dependencies.

See also: |pencil-installation| |pencil-configuration| |pencil-api|
|pencil-commands| |pencil-safety| |pencil-license|

*pencil-installation*
INSTALLATION

Install jrswab/pencil.nvim with a plugin manager, or add the repository to
Neovim's 'runtimepath':

    { "jrswab/pencil.nvim" }

Loading the plugin registers the bare |:Pencil| command. No setup call is
required. The repository is https://github.com/jrswab/pencil.nvim.

*pencil-configuration*
CONFIGURATION

Configuration is optional. The default preferred display width is 80:

    require("pencil").setup({ width = 80 })

`width` is the only accepted key and must be a positive integer. Unknown keys,
non-table values other than nil, and invalid widths raise an error. Validation
is atomic: a failed setup leaves the previous preference and active
presentations unchanged.

    require("pencil").setup({ width = 100 })
    require("pencil").setup({})       " restore the default for later activations
    require("pencil").setup(nil)      " leave the preference unchanged

Setup changes affect future activations only. An active buffer retains the
preferred width captured when it was enabled. A preference wider than a
window contracts safely to the available text area.

*pencil-api*
LUA API

    local pencil = require("pencil")
    pencil.setup({ width = N })
    pencil.enable(opts?)
    pencil.disable(opts?)
    pencil.toggle(opts?)

`setup()` accepts nil or a table containing only `width`. The control functions
accept nil, or `{ buf = bufnr }` for an explicitly targeted valid buffer. With
nil, the current buffer is targeted. `enable()` and `disable()` are idempotent;
`toggle()` switches the selected buffer's state. These are the complete public
Lua exports.

*pencil-commands*
COMMANDS

    :Pencil

Bare `:Pencil` toggles the current buffer and accepts no arguments. There are
no subcommands or aliases.

*pencil-safety*
BEHAVIOR AND SAFETY

When enabled, Pencil centers a preferred visual column in every window showing
the buffer and wraps long lines visually. Empty and short buffers receive the
same presentation. Buffer text and hard line breaks are never changed; tabs
and Unicode are measured using Neovim's display rules.

The presentation follows relevant resize, split, and buffer/window lifecycle
events. Each window has an independent baseline. Disabling restores each
presentation value still owned by Pencil exactly. If an external edit changes
an owned value while Pencil is active, that value is preserved. Narrow windows
contract safely, and repeated reconciliation does not compound margins.

Pencil does not insert hard breaks, autoformat during insert, auto-enable by
filetype, configure filetype widths, install mappings, manage concealment,
classify protected regions, provide statusline integration, or preserve old
commands/configuration compatibility.
